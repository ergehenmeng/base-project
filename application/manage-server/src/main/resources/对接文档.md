> 这是我方给第三方提供的对接文档的签名文档, 具体对接接口请联系开发人员核对

* 签名方式: `hmacSha256` 根据提供的签名信息进行对接
* appId: appId
* appSecret: 签名秘钥

### 请求方式

> 支持GET POST接口的签名。 Header中增加以下三个字段：

* `X-App-Id` appId
* `X-Timestamp`  当前时间毫秒值
* `X-nonce` 随机串不能超过128位
* `X-Sign` 签名信息

### 示例

> GET

```
http://host:port/get?query=a&state=b&mark=c
```
data = `base64(query=a&state=b&mark=c)` = `cXVlcnk9YSZzdGF0ZT1iJm1hcms9Yw==`

> POST

- Content-Type: application/json

```json
{"query":"a","state":"b","mark":"c"}
```

data = `base64({"query":"a","state":"b","mark":"c"})` = `eyJxdWVyeSI6ImEiLCJzdGF0ZSI6ImIiLCJtYXJrIjoiYyJ9`

### 签名信息生成

* 将data、timestamp、nonce、data该顺序进行字符串拼接
* 使用 `appSecret` 作为签名秘钥进行 `hmacSha256` 进行签名(16进制字符串)
* signature=上述签名结果

### 示例

```java
// post - rsa
JSONObject jsonObject = new JSONObject();
jsonObject.put("query", "a");
jsonObject.put("state", "b");
jsonObject.put("mark", "c");

String strToSign = appId + timestamp + nonce + Base64.encode(jsonObject.toString().getBytes(StandardCharsets.UTF_8));
HMac mac = SecureUtil.hmacSha256(appSecret.getBytes(StandardCharsets.UTF_8));
String signHex = mac.digestHex(strToSign);


// get - md5
String strToSign = appId + timestamp + nonce + Base64.encode("query=a&state=b&mark=c".getBytes(StandardCharsets.UTF_8));
HMac mac = SecureUtil.hmacSha256(appSecret.getBytes(StandardCharsets.UTF_8));
String signHex = mac.digestHex(strToSign);
```
